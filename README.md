# **Primeiros passos em análises de dados e visualizações gráficas com Python**

Material utilizado no curso **"Primeiros passos em análises de dados e visualizações gráficas com Python"** que ocorreu na Semana Temática da Biologia no Instituto de Biociências da Universidade de São Paulo (USP) nos dias 7, 8 e 9 de outubro de 2026.

O respositório é composto de:
1) [Material adicional](https://github.com/mariguilardi/STBioPython/blob/main/MaterialAdicional_CursoPython.pdf): PDF para configuração do ambiente Google Colab para execução dos notebooks (arquivos .ipynb)
2) [Dia 1](https://github.com/mariguilardi/STBioPython/tree/main/Dia%201): material sobre Python Básico com PDF, material com códigos em formato de notebook e notebook com exercícios
3) [Dia 2](https://github.com/mariguilardi/STBioPython/tree/main/Dia%202): arquivos de notebooks sobre Python Pandas para manipulação de planilhas e planilha com dados abertos sobre pinguins.
4) [Dia 3](https://github.com/mariguilardi/STBioPython/tree/main/Dia%203): apresentação em PDF com materiais adicionais para estudar Python, notebook sobre Estatística Descritiva e gráficos em Python, notebook com exercícios para limpeza de dados, inferência e produção de gráficos, e planilhas para serem utilizadas com notebooks.

Os notebooks que finalizam com _COMPLETO apresentam os códigos mostrados em aula e aqueles com _ALUNOS não apresentam os códigos.
